# BrandProof Desk → Agentverse (FastAPI / ACP)

This integration runs a separate, minimal ACP-only FastAPI service on port 8001. Keep the main BrandProof REST API on port 8000 private; tunnel only the ACP service.

## 1. Install the added dependency

From `backend/` with the virtual environment active:

```powershell
pip install -r requirements.txt
```

## 2. Create a stable agent seed

Generate a secret once:

```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Copy the output into `backend/.env`:

```env
AGENT_SEED_PHRASE=
```

Keep it private and do not change it after registration. Never commit `.env`.

## 3. Restart FastAPI

```powershell
python -m uvicorn agentverse_server:app --host 0.0.0.0 --port 8001 --reload
```

Run this command from `backend/` in a separate terminal. Keep your existing BrandProof backend on port 8000 running for the dashboard. Check the ACP health endpoint locally:

- `http://localhost:8001/status`
- `http://localhost:8001/docs` (look for `POST /chat`)

`GET /status` should return `status: ok` and `identity_configured: true`.

## 4. Create a temporary public HTTPS URL (development only)

Install Cloudflare Tunnel if needed:

```powershell
winget install -e --id Cloudflare.cloudflared
```

Close and reopen PowerShell if `cloudflared` is not found immediately. Then run in a third terminal:

```powershell
cloudflared tunnel --url http://localhost:8001
```

Keep this terminal open. Copy the generated `https://....trycloudflare.com` URL and append `/chat`.

Example shape only (do not copy this example):

```text
https://random-words.trycloudflare.com/chat
```

Open the base tunnel URL plus `/status` in a browser to confirm it returns the BrandProof Desk ACP status JSON. Use the `/chat` URL in Agentverse.

Quick Tunnels are temporary and the URL changes when the process stops. They are for development/testing, not production. Anyone with the URL can reach the local service, so stop the tunnel when finished and do not expose secrets or admin-only endpoints unnecessarily.

## 5. Continue Agentverse onboarding

1. Agent name: `BrandProof Desk`
2. Agent endpoint URL: the real generated public URL ending in `/chat`
3. Add truthful discovery keywords such as `brand governance`, `content compliance`, `brand guidelines`, `claim review`, `marketing content review`.
4. Continue and run the registration script generated by Agentverse. Use the Agentverse API key requested by that script, plus the same `AGENT_SEED_PHRASE` used by the running app.
5. Evaluate registration and test an ACP chat message.

## Important

- Do not enter `localhost`, `127.0.0.1`, a placeholder hostname, or the frontend Vite URL.
- Do not enter the Cloudflare root URL without `/chat`.
- This adapter uses the existing BrandProof deterministic checks and Adaption AI analysis configured in the backend. If Adaption is not configured, responses identify `rules_fallback`; that is not live LLM mode.
- The public `/chat` endpoint accepts ACP envelopes; it is not a normal JSON chat endpoint. Only the isolated ACP service on port 8001 is exposed; keep the dashboard REST API on port 8000 private.
